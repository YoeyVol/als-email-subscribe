# ALS 邮件订阅中心 / ALS Email Subscription Hub

一页式静态网站，汇总渐冻症（ALS / MND）官方组织的 **邮件 / newsletter 订阅入口**。  
点击「订阅邮件」会在新标签页打开对应组织的官方订阅页；**本站不收集、不存储任何邮箱**。

Live: https://yoeyvol.github.io/als-email-subscribe/
